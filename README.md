# Phishing Awareness Simulation – Demo Page

A fake login page built for a controlled, consent-based phishing awareness
exercise, as part of a college cybersecurity minor/major project.

## ⚠️ Disclaimer

This page is **for educational use only**, inside a supervised awareness
exercise with informed consent from all participants. It does **not**
collect, store, or transmit any data entered into it. No real credentials
are processed, logged, or sent anywhere — the password field is cleared
the moment the form is submitted.

## What this is

A single-page HTML/CSS mockup of a generic "account verification" login
screen, used to demonstrate common phishing techniques (urgency, a fake
security alert, a link-based login page) to a small, consenting test
group. After submitting the form, the page reveals that it was a
simulation and explains what gave it away.

## How it works

1. A simulated phishing email is sent to a consenting test group, linking
   to this page.
2. If someone enters text and submits the form, the page immediately
   clears the input and shows an awareness/debrief message — nothing is
   saved or sent.
3. Participants are asked to self-report (e.g. reply "I submitted it" or
   "I reported it") so results can be tallied manually.
4. Results are summarized anonymously in the project report.
